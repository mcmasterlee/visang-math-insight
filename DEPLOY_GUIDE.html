웹 링크로 공유하기 — 가장 쉬운 방법

GitHub는 코드 보관, Vercel은 실제 웹주소 제공, Supabase는 여러 사람이 함께 보는 데이터를 저장하는 역할입니다.

1GitHub 저장소 만들기

GitHub 새 저장소 만들기를 엽니다. 저장소 이름은 visang-math-insight처럼 입력하고 생성합니다.

GitHub Desktop을 설치하면 명령어 없이 폴더 전체를 올릴 수 있습니다: GitHub Desktop.

2Supabase 데이터 저장소 만들기

Supabase Dashboard에서 새 프로젝트를 만듭니다.

SQL Editor를 열고 이 폴더의 docs/SUPABASE_SETUP.sql 내용을 전부 붙여 넣고 Run을 누릅니다.

Project Settings의 API 메뉴에서 Project URL과 서버용 Secret key를 복사해 둡니다.

Secret key는 웹페이지나 GitHub 파일에 직접 적으면 안 됩니다. 다음 단계의 Vercel 환경변수 칸에만 넣습니다.

3Vercel로 웹앱 배포

Vercel New Project에서 방금 만든 GitHub 저장소를 선택하고 Import합니다.

Environment Variables에 아래 7개 환경변수 이름을 하나씩 등록하고, 실제 값은 Vercel 화면의 Value 칸에만 붙여넣습니다: NAVER_CLIENT_ID, NAVER_CLIENT_SECRET, OPENAI_API_KEY, OPENAI_MODEL, SUPABASE_URL, SUPABASE_SECRET_KEY, CRON_SECRET.

그 다음 Deploy를 누르면 https://프로젝트이름.vercel.app 형태의 공유 주소가 생깁니다.

4업데이트

웹앱에서 전체 교재 업데이트를 누르면 20종을 순서대로 갱신합니다. vercel.json에는 매일 한국시간 오전 3시대에 전체 교재를 갱신하도록 자동 실행 설정도 포함되어 있습니다.

파일을 수정할 필요는 없습니다

GitHub에 올리는 파일은 수정할 필요가 없습니다. 실제 API 키는 Vercel 환경변수 화면에만 입력합니다. 나머지 검색 정확도, 학교급 분류, 키워드 필터, 원문 링크, UI 모션, 데이터 저장 코드는 프로젝트에 포함되어 있습니다.
