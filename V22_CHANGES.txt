v22 신규 콘텐츠
- 왼쪽 메뉴 탭: 후기 인사이트 / 시장 반응 / 교재 비교
- 시장 반응: 온라인 반응 지수(0~100), 학교급 내 순위, 후기량, 긍정률, 최근 30일, 출처 다양성, 키워드 근거율
- 지수 산식: 후기량 35% + 긍정률 30% + 최근 반응 15% + 출처 다양성 10% + 키워드 근거율 10%
- 데이터가 없는 항목은 자동 재가중. 실제 판매량/시장점유율은 추정하지 않고 미연결 표시.
- 교재 비교: 같은 학교급 교재들을 동일 기준으로 순위/표 비교
- 비교 카드 클릭 시 해당 교재 후기 인사이트로 이동
