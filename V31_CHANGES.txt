v31 — 사용자 관점 분류
- 공개 용어 변경:
  긍정 → 높은 선호도
  중립 → 중립
  부정 → 개선 요구
- OpenAI가 각 후기마다 userClass를 직접 판정:
  high_preference / neutral / improvement_request
- 높은 선호도: 실제 사용 경험 기반의 만족·추천·학습 효과·재구매 의사 등
- 중립: 파일 요청·자료 공유·구매 문의·출간 정보 등 평가가 뚜렷하지 않은 정보성 게시물
- 개선 요구: 전체적으로 좋은 글이어도 실제 사용 중 아쉬움·난이도 부담·설명 부족·문제량·해설 등 개선 포인트가 있으면 포함
- 후기 목록 표시:
  높은 선호도 = 초록 점 + '높은 선호도' 배지
  개선 요구 = 빨간 점 + 개선 유형 배지
  중립 = 별도 표시 없음
- 그래프의 '높은 선호도'와 '개선 요구' 클릭 시 해당 후기만 필터링
- 수치는 현재 화면에 실제 존재하는 AI 분류 후기만으로 계산
